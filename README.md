# Pulse — асинхронный мессенджер

Браузерный мессенджер с регистрацией и подтверждением email, личными и групповыми чатами, обменом сообщениями в реальном времени через **WebSocket**, поиском пользователей, аватарами, уведомлениями и настройками конфиденциальности.

## Стек

- **Frontend:** React 19 + Vite, lucide-react, собственные стили (адаптивный интерфейс).
- **Backend:** Node.js + Express, `ws` (WebSocket), SQLite (`better-sqlite3`), JWT + bcrypt, Nodemailer.
- **Обмен данными:** REST API + WebSocket (`/ws`), heartbeat и автоматическое переподключение.

## Быстрый старт

Требуется Node.js **20.19+** (проверено на Node 24).

```bash
npm install          # устанавливает зависимости server и client (npm workspaces)
npm run dev          # сервер :3001 и Vite :5173
```

Откройте <http://localhost:5173>.

Для production-режима:

```bash
npm run build        # сборка клиента в client/dist
npm start            # Express раздаёт собраный клиент и API на :3001
```

### SMTP (подтверждение регистрации)

Скопируйте `.env.example` в `.env` и заполните данные почтового сервера:

```env
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_USER=your-account@yandex.ru
SMTP_PASS=your-app-password
SMTP_FROM=your-account@yandex.ru
JWT_SECRET=длинная-случайная-строка
```

Для Google: `SMTP_HOST=smtp.gmail.com`, `SMTP_PORT=465`, пароль приложения.

**Демо-режим:** если SMTP не настроен, код подтверждения выводится в консоль сервера и одновременно возвращается в ответе API — на экране подтверждения он показан отдельным блоком. Это позволяет протестировать регистрацию без реальной почты.

## Возможности

**Задача 1 — базовый функционал**

- Регистрация по email с подтверждением кодом, вход по email/паролю, JWT-сессии.
- Уникальный nickname (проверка занятого ника с ошибкой), уникальный email.
- Скрытие email: скрытый email не ищется и не выдаётся другим пользователям.
- Загрузка аватара (автоматическое уменьшение до 256×256, JPEG), стандартный аватар при отсутствии.
- Список чатов и контактов, личные сообщения, поиск пользователей и добавление в контакты.
- Сообщения в реальном времени через WebSocket, индикатор «печатает…», статусы «в сети».
- Профиль: смена ника, аватара, видимости email.

**Задача 2 — групповые чаты и улучшения**

- Создание групповых чатов, добавление участников из контактов, выход из группы.
- Контекстное меню сообщения (правый клик): редактирование, удаление, пересылка контакту.
- Контекстное меню чата (правый клик): включение/отключение оповещений; чат с отключёнными уведомлениями визуально отличается.
- Короткий звуковой сигнал через Web Audio API при новом сообщении (в неотключённом чате).
- Счётчик непрочитанных, исключение отключённых чатов из общего счётчика.

## Проверка работы

```bash
node scripts/smoke-test.mjs   # при запущенном сервере :3001
```

Скрипт проверяет регистрацию и верификацию, приватность email, контакты, личные и групповые чаты, доставку через WebSocket, редактирование/удаление/пересылку и беззвучный режим.

## Деплой

Приложение можно задеплоить на любой Node.js-хостинг (Render, Railway, Fly.io и т.п.):

- **Build command:** `npm install && npm run build`
- **Start command:** `npm start`
- **Environment:** `PORT` (хостинг задаёт сам), `JWT_SECRET`, при необходимости SMTP-переменные.

После сборки Express раздаёт клиент из `client/dist` и одновременно обслуживает REST API и WebSocket на одном порту.

## Структура

```

  app.js            Express + раздача клиента
  config.js, db.js  конфигурация и SQLite-схема
  realtime.js       WebSocket, presence, typing, read
  routes/           auth, users, contacts, chats, messages
client/src/
  App.jsx           состояние приложения, обработка событий WS
  components/       AuthScreen, Sidebar, Rail, ChatWindow, Modal и др.
  styles.css        дизайн-система и адаптивность
data/messenger.db   база данных (создаётся автоматически)
```
